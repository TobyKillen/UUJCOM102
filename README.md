# UUJCOM102 - Java Coursework

This repository contains Java coursework for the Ulster University (UUJ) COM102 module.

## What is included?
- Java source files for the assignment
- A simple object-oriented design example using classes and interfaces

## Getting started
Compile and run the Java files from the repository root:

```bash
javac *.java
java Main
```

## Notes
- This project is focused on core Java programming concepts.
- The code is intended as coursework material and may be adapted for learning purposes.
